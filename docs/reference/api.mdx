## Client

<ApiEntry
  kind="function"
  name="init"
  since="since 0.1"
  lang="ts"
  signature={`import { init } from "@casoon/trackr/client";

function init(options: TrackrConfig): void;

interface TrackrConfig {
  endpoint: string;
  debug?: boolean;
}`}
  params={[
    { name: 'endpoint', type: 'string', desc: 'URL the events are posted to, usually a route on the same site.' },
    { name: 'debug', type: 'boolean', desc: 'Log every sent event to the console.' },
  ]}
>
  Sends a pageview and, from 0.2, a pageview after every `pushState`, `replaceState`,
  `popstate` and `hashchange`. Call it once per page load.
</ApiEntry>

<ApiEntry
  kind="function"
  name="track"
  since="since 0.1"
  lang="ts"
  signature={`import { track } from "@casoon/trackr/client";

function track(name: string, props?: Record<string, string | number | boolean>): void;`}
>
  Sends a custom event for the current path. Before `init()` it only logs a warning.
</ApiEntry>

## Server

<ApiEntry
  kind="function"
  name="createHandler"
  since="since 0.1"
  lang="ts"
  signature={`import { createHandler } from "@casoon/trackr/server";

function createHandler(config: HandlerConfig): (request: Request) => Promise<Response>;

interface HandlerConfig {
  storage: StorageAdapter;
  privacy?: PrivacyConfig;
  botFilter?: boolean;
}

interface PrivacyConfig {
  anonymizeIp?: boolean;     // default true
  stripPii?: boolean;        // default true
  stripQueryParams?: string[];
}`}
  params={[
    { name: 'storage', type: 'StorageAdapter', desc: 'Receives every accepted event.' },
    { name: 'privacy', type: 'PrivacyConfig', desc: 'Merged with the defaults; see the Privacy guide.' },
    { name: 'botFilter', type: 'boolean', desc: 'Drop requests that look like bots. Off unless set.' },
  ]}
>
  Accepts `POST` with a JSON event. Status codes are listed in the
  [Quickstart](../../getting-started/quickstart/).
</ApiEntry>

<ApiEntry
  kind="function"
  name="createPixelHandler"
  since="since 0.2"
  lang="ts"
  signature={`import { createPixelHandler } from "@casoon/trackr/server/pixel";

function createPixelHandler(config: HandlerConfig): (request: Request) => Promise<Response>;`}
>
  Records a pageview from the `url` and `ref` query parameters and returns a transparent GIF.
  See [Tracking pixel](../../guides/pixel/).
</ApiEntry>

`@casoon/trackr/server` also exports the building blocks the handler uses: `isBot(request)`,
`anonymizeIp(ip)`, `stripPii(url)`, `sanitizeProps(props)`, `applyPrivacy(event, config)` and
`resolvePrivacyConfig(config)`.
